this plugin should use that library to render a clock.

# day calendar
Plugin should have a timeline for the day.

user specifies ics links with colors for each link.

the day should progress like a progress bar, indicated by a line running across the calendar events.

windows on each desktop should be visible as tiny rectangles in each virtual desktop
